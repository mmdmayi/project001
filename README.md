# FaceInverse 0.3.0 Windows x64 / Maya 2024

1. 解压到有写权限的目录。
2. 双击 INSTALL.bat 安装独立运行环境。
3. 双击 VERIFY.bat 验证。
4. 双击 OPEN_MAYA_TOOL.bat，或在 Maya 中运行 scripts/launch_ui.py。

详细中文说明：docs/PACKAGE_INSTALL_CN.md 与 docs/USER_GUIDE_CN.md。

不包含角色、DNA 或 Epic 插件。
此为联网安装包：首次运行 INSTALL.bat 会下载固定版本运行时、依赖和模型。
