# FaceInverse 0.3.1 / Maya 2022 / Windows x64

1. 完整解压到有写权限的目录。
2. 双击 INSTALL.bat 安装独立运行环境。
3. 双击 VERIFY.bat 验证依赖和数值测试。
4. 双击 OPEN_MAYA_TOOL.bat，选择本机角色和对应插件，保存设置。
5. 双击 VERIFY_MAYA.bat 验证本机角色实际变形。

安装与操作：docs/PACKAGE_INSTALL_CN.md、docs/USER_GUIDE_CN.md。Maya 2022 专项：docs/MAYA2022_INSTALL_CN.md。
不包含 Maya、角色、DNA 或 Epic 插件。默认关闭未标定幅度补偿；表演还原精度仍需逐片段验收。
此为联网包，首次安装需要下载运行时、依赖和官方模型。
