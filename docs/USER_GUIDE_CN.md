# FaceInverse 0.3.1 操作说明

## 1. 建立项目

打开工具，在“项目与视频”选择能正常驱动的 MetaHuman 中性、无动画角色场景，设置 mayapy 和角色已有的执行插件。选择视频、新项目目录、截取起点和时长。首次建议处理 10–15 秒。

点击“新建项目”。后台采样 Faceboard 响应、追踪视频、生成初始 baseline.mb、参考帧缓存及 session.json。完成后切到“关键表情插帧”，点击“打开最近动画场景”。当前场景有未保存修改时，工具会提示后才替换。

## 2. 记录关键表情

1. 通过视频帧数字、滑块、建议表情列表或播放按钮浏览参考。视频帧从 0 开始。
2. 默认同步 Maya 时间，也可以从当前 Maya 时间反向定位参考帧。
3. 停在关键帧，在 Maya 调整现有控制器，使目标角色达到所需表情。建议自动关键帧或按 S 保留调整。
4. 选择作用范围：全部、眉、眼、嘴鼻、下颌，或仅 Maya 所选控制器。
5. 输入名称，选择计算方式，点击“记录新表情样本”。记录前播放会停止。

### 按相似表情传播

模型依据视频表情描述学习相对初始动画的修正，会影响片中其他相似表情，而非仅在时间线上插值。表情半径小则作用更局部，大则覆盖更多相似表情，建议从默认 2 开始。

同一表情被标成互相矛盾的目标时会报错。请禁用错误样本、更新它，或把一次性修正改为局部模式。

### 局部修正

只影响该时间附近，“局部半径 / 秒”控制范围，适合特定嘴型、遮挡或一次性细修，不传播到全片所有相似表情。

### 精确关键帧

勾选后，该帧记录的通道值会被精确保留，平滑不会抹掉它。只记录眼睛就只锁眼部通道；要锁住完整表情，请记录全部控制器。

## 3. 重算与迭代

点击“按关键表情重新计算并烘焙新版本”，完成后打开最近结果。计算始终以原 baseline 为基准，不累计叠加上一轮修正，不覆盖原始角色或基线。

可反复增加样本：先记录中性、张嘴、闭眼、微笑、嘴角下压、抬眉和噘嘴，再补说话时的局部唇形。不要把追踪丢失帧当可靠标定样本。

## 4. 管理样本

- 双击行：跳到对应参考帧。
- 载入所选样本到 Maya：将存储值打到它自己的帧，便于再编辑。
- 更新所选：修改当前样本，不新增重复条目。
- 启用/禁用：比较有无该样本；删除仍保留项目历史。
- 导出/导入样本库：保存为 JSON，供兼容控制器及描述定义的其他片段使用。
- 日志页“恢复项目历史”：选择本项目 history 快照。

跨片段的表情样本可传播；不会在新片段错误地锁定旧帧号，时间局部样本也不会跨片段应用。更换演员/角色建议重新标定。

## 5. 数据和命令行

session.json 保存样本，history 保存修改前快照，runs 保存每次结果及当时样本。latest.json 指向最近成功结果；失败不会覆盖上一个成功版本。

搬运时带上整个项目目录以及源素材备份。baseline 被外部修改或角色标定签名变化时，工具会拒绝继续使用旧样本。

已有项目重算：

```bat
RUN_PROJECT.bat solve "D:\项目\session.json"
```

目标 Maya 时间为 24 fps，按视频时间生成分数关键帧，可处理本轮验证的 29.97 fps 恒定帧率素材。VFR 请先转换成恒定帧率。

本工具实现选帧、手调目标表情、记录标定样本、按表情重算的操作方式，不声称复制 Faceware / Facegood 专有算法或已达到相同产品精度。详见 RELEASE_TESTS.md。


## Maya 2022 版本

2022 专项安装、Python 3 模式、插件版本和跨电脑迁移见 MAYA2022_INSTALL_CN.md。0.3.1 默认关闭未标定的幅度补偿；请用新建项目采用新默认。保存本机路径设置后，运行 VERIFY_MAYA.bat 验证实际角色；VERIFY.bat 仅验证依赖和数值算法。
