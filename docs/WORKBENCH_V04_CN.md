# FaceInverse 0.4 工作台操作说明

日期：2026-10-29。支持 Windows x64 / Maya 2022 Python 3 / Maya 2024。计算环境与 0.3.1 相同，未新增科学计算依赖。

## 安装和启动

完整解压后运行 INSTALL.bat，再运行 VERIFY.bat。OPEN_MAYA_TOOL.bat 启动 Maya 工具，OPEN_TRACKER.bat 打开独立 Tracker；后者使用目标 Maya 自带的 PySide2 显示界面，由独立 Python 运行追踪，不把 MediaPipe/NumPy/SciPy 装进 Maya。目标电脑仍需安装相应版本 Maya；角色运行还需要对应插件、素材和正确路径。安装路径有变化时重新运行 INSTALL.bat。

## 1. Tracker 可视化

在独立 Tracker 或 Maya 工具的 Tracker 页选择视频，点击“读取 / 预览”。可以看容器帧率、方向元数据和预处理后的画面。**先设置“追踪前旋转”把脸转正，再自动追踪**。默认先应用文件方向元数据，再叠加手工顺时针 0/90/180/270 度。每次追踪生成新目录，不覆盖旧结果。

完成后可逐帧、播放、查看478点或眉/眼/嘴轮廓，放大所选区域，查看表情系数曲线和单帧系数。红色时间线标记表示未检出，系数不是校准后的检测置信度。可将某帧标为“通过目视检查”或“需要修正”，保存在 tracking_review.json；这是检查记录，不会自动修改求解器。

修改追踪前旋转后，旧结果的显示失效并提示重新预览/追踪，不会把新方向画面与旧点位组合。也可重新打开旧 tracking.json 检查旧版。**本版没有实现 FACEGOOD 的人工拖点训练模型**，不能将仅看见点位描述为实现了其专有训练算法。

## 2. Maya 的视频参考

“关键表情插帧”页显示视频及区域追踪点。“参考显示旋转”只旋转该页的参考画面，叠加点会一起旋转；不改输入追踪、模型系数、关键表情描述或解算结果。这与 Tracker 的“追踪前旋转”是两个独立设置。

视频帧从0开始，旁边同时显示源视频帧、相对秒数、Maya帧及项目输出帧率。可用滑块或数字定位，也可勾选“跟随 Maya 时间轴”反向定位；即使当前 Maya 场景的时间单位与项目不同，也先按实际秒数转换。播放根据经过时间推进，避免将60fps强制按24fps播放。

## 3. 输出帧率

新项目默认自动匹配视频和 Maya 原生时间单位，也可选择24、25、29.97、30、50、59.94、60，或输入本版支持的 Maya 原生帧率（如100/120/240）。不支持的手工数值会明确报错。

Maya 的“29.97fps”实际使用30000/1001，“59.94fps”使用60000/1001。工具保存实际分数帧率并据此生成关键帧；不会简单截短为29.97。对于可变帧率，以解码时间戳计算，不用帧号除标称帧率。自动模式遇到非原生平均帧率会选择最近的已支持Maya时间单位，并在信息中显示映射；实际时间仍按秒对齐。

输出帧率不同于源帧率时，保留每个源采样的时间，Maya关键帧可以是分数帧，不通过丢帧来凑整数。手选输出帧率不会改变视频播放速度。

已有项目改变帧率：先在“项目与视频”选择输出帧率、起始帧，再点“以所选输出帧率建立新版本”。工具复制工程、保留样本和输入，重新映射时间并烘焙；原baseline和旧工程保留。

解码器若无法给出递增时间戳，本版可标记 nominal_cfr_fallback（只可作为CFR近似）；时间戳倒退会报错，不能声称所有格式/VFR都已支持。

## 4. 眉、眼、嘴分组和添加控制器

在“控制器分组”可新建、重命名、删除组；从已标定通道列表或 Maya 当前所选控制器添加，也可移除成员。组可包含不同区域，按制作需求组织。样本页选择“组 · 眉毛/眼睛/嘴和鼻”等后记录，只记录组内通道。

修改组不会改写已记录样本：旧样本保存的是当时的明确通道和值。新增已标定、但当前初始动画没有的通道时，会自动创建扩展工程新版本，以中性值补足该通道，再保留样本重算；原工程不覆盖。未标定的任意节点不能直接加入求解，需在新的角色标定中纳入。

分组定义保存在 session.json。原有0.3工程无分组定义时按命名生成默认组。导出的Pose样本仍存明确通道掩码，避免后来改组改变旧结果。

## 5. 自动参考动作候选

原先程序无论有无该表情都取全片最大值，例如整片只有弱嘴角信号也给“微笑参考”。0.4将这些改为“嘴角拉起/内眉抬起/闭眼”等**待确认动作候选**，加绝对阈值和邻帧支持；嘴角拉起还需存在低活动参考及相对嘴角上移，否则不推荐。可以没有任何嘴角拉起候选，不强行给一个。

这些规则只是保守筛选，不是已训练的FACS AU识别器，也不输出情绪结论。请看视频确认，再手动调整角色并“记录新表情样本”。弱表情可能被漏掉时，仍可自行选帧录制。

## 6. 重算算法

沿用0.3.1有界语义基线与关键表情修正；权重、正则、修正核、半径和平滑默认值不变。参考帧推荐只影响导航，不作为自动标定真值。帧率修订只改变时间映射；分组控制录制通道掩码，均不替换数值求解算法。


## Tracker → Maya 交接与升级

完成Tracker检查后，在Maya项目页选择角色和新项目目录，点“使用 Tracker 当前结果新建角色项目”，可直接复用追踪和参考缓存。可先在Tracker页打开独立Tracker生成的 tracking.json，再交接。复用时会检查源路径、文件状态与输入方向；不匹配必须重新追踪。

升级建议退出旧Maya/Tracker后解压新目录并安装，避免Python进程继续使用旧模块。旧工程若最初对横向视频追踪，仅旋转参考不能修复特征；应新建转正的Tracker和角色项目，并重新核对/录制Pose。原有样本描述不能被当成新方向追踪的真值。
