# FaceInverse 0.3.1 / Maya 2022 验证结果

日期：2026-10-27（中国时区）。平台：本机 Windows x64。

## 实际验证环境

- Maya 2022，API 20220000，Python 3.7.7，PySide2 5.15.2。
- 该 Maya 版本对应的 embeddedRL4 2.10.3.5 插件；只加载角色已有绑定，不修改 DNA/RBF/RigLogic。
- 外部安装器建立私有嵌入式 Python 3.12.10、NumPy 1.26.4、SciPy 1.15.3、MediaPipe 0.10.21、OpenCV 4.11.0.86。未向 Maya Python 安装这些库。
- 中文及空格路径中的全新离线安装通过；另一个完全不带运行时、Wheel、模型的联网安装通过。两个独立运行时均通过 32 项数值测试和模型初始化。

## 真实 MetaHuman 视频与场景

使用本机既有 full_riglogic.mb（较新 Maya 来源，明确允许尝试读取），通过 2022 匹配插件实际评价；输出重新由 Maya 2022 保存。此场景成功不保证任意新版本场景向下兼容。

| 真人输入 | 帧数 / 检出 | Faceboard 控制器 | 已保存关键帧数 | 独立 Maya 2022 进程重开后的最大控制器误差 |
| --- | ---: | ---: | ---: | ---: |
| 说话片段（12–36 秒） | 719 / 719 | 60 | 43,140 | 0 |
| 愤怒表演 | 67 / 67 | 60 | 4,020 | 0 |
| 开心表演 | 56 / 56 | 60 | 3,360 | 0 |

共 842 帧、50,520 个关键帧。各输出重开后仍有实际 Mesh 动作；采样得到 68 个有效有符号分支，最大采样 Mesh 分量响应约 3.24231 cm。默认经验幅度辅助均为关闭。

## 关键表情界面

在 Maya 2022 standalone 中使用真实 PySide2/Qt 离屏界面，以 Qt 鼠标事件操作记录、启用/禁用、重算按钮。3 个脚本制作的表情样本、180 项控制器硬约束，经求解、真实 Maya 2022 烘焙与重新打开后，控制器最大误差为 0，采样 Mesh 坐标最大误差为 0 cm。截图保存在 reports/maya2022_ui.png。

这些是脚本制作的动画师操作夹具，不是独立标注的视频真值；采样 Mesh 为部分顶点，不表示全脸24k顶点视频重建误差为0。未把离屏 Qt 验证描述为真人全流程手工交互测试。

## 安装与失败检查

- 本包 VERIFY_MAYA.bat 实际运行通过，记录真实宿主 2022、非零 Mesh 响应和60个活跃控制器。
- 父环境设置 MAYA_PYTHON_VERSION=2 时，工具工作进程仍明确选用 Python 3 并通过实际角色验证。
- 2022 宿主配成 maya_version=2024 时明确失败。
- 使用 Maya 2022 原生生成的“诊断属性变化、Mesh 不动”夹具，明确以 RIG_NO_MESH_RESPONSE 拒绝，未产生成功标定文件。
- 最初复用的 2024 ASCII 负例夹具有 2022 不支持的 displayLayer 属性，未到达变形检查；改用原生2022夹具后才验证该失败门槛，未通过修改源角色绕过。
- 原始角色场景与 DNA 在完整视频测试前后 SHA-256 一致。
- 共享代码的 Maya 2024 实际响应采样和30帧烘焙回归通过。
